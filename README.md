## 📚 Learning Roadmap

### 1. Excel & Advanced Excel
- Data cleaning and preparation
- Excel formulas and functions
- Data analysis and manipulation
- PivotTables and PivotCharts
- Data visualization and reporting

### 2. SQL
- Database fundamentals
- SELECT statements and filtering
- Aggregate functions
- GROUP BY and HAVING
- Joins and subqueries
- Data manipulation and analysis
- Practice problems and assignments

### 3. Python Programming
- Python fundamentals
- Variables, data types, and operators
- Conditional statements and loops
- Functions and modules
- Lists, tuples, sets, and dictionaries
- Problem-solving and programming exercises

### 4. Data Structures
- Fundamental data structures
- Lists, stacks, queues, and dictionaries
- Searching and sorting concepts
- Problem-solving techniques

### 5. Data Analysis with Python
- **NumPy** — Numerical computing and array operations
- **Pandas** — Data manipulation and analysis
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Exploratory Data Analysis (EDA)

### 6. Data Visualization
- **Matplotlib** — Creating charts and visualizations
- **Seaborn** — Statistical data visualization
- Identifying patterns and trends
- Communicating insights through visualizations

### 7. Business Intelligence
- **Power BI** — Data modeling, interactive dashboards, and reporting
- **Tableau** — Data visualization and dashboard development
- Transforming data into meaningful business insights

### 8. Machine Learning
- Machine learning fundamentals
- Data preprocessing
- Exploratory Data Analysis
- Linear Regression
- Model training and evaluation
- Additional algorithms and techniques as I progress
